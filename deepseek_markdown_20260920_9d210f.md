# PROMPT-MESTRE - Evolucao do Sistema

## Contexto
Sistema HTML com Supabase (auth, banco, storage).
Modulos: processos, documentos, tramitacao, fases, prazos, notificacoes.

## Regras
- Nao remover funcionalidades existentes
- Nao alterar chaves de localStorage sem migracao
- Nao colocar service_role key no front
